# Library Management System

A desktop-based Java application for managing university library operations using Java Swing and MySQL.

**Author:** Serena Haidar
**Technologies:** Java, Java Swing, MySQL

---

## Project Overview

This system streamlines book and student management in university libraries, replacing manual paperwork and Excel files with a simple GUI-based desktop app.

**Key Features:**

* Built with Java Swing (NetBeans)
* MySQL database integration
* Admin-only access
* Designed for offline use

---

## Features

* **Admin Login**: Secure login system to restrict access
* **Book Management**: Add, edit, delete, and search books
* **Student Management**: Add students and manage their borrowing records
* **Borrow/Return Handling**: Track loans and returns with borrowing limits (3 books max, 2-week return policy)
* **Student Profiles**: View student info and borrowing history
* **Logout**: Secure session termination

---


## Business Rules

* Only the librarian can access the system.
* Student accounts must be created before borrowing.
* A student may borrow up to 3 books at once.
* Books must be returned within 14 days.

---

## Benefits

* Works offline
* Cross-platform compatibility via JVM
* Intuitive GUI
* Secure and simple login
