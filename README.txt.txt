Project Name: Library Management System
Authors : Serena Haidar
Technologies used : Java, Java Swing, MySQL.


Description
This project is a library management system developed as part of our summer training I. It includes a desktop application that manages library resources, built using Java, Java Swing, and MySQL.


Contents
- Java Project : the complete source code of the project, implemented using NetBeans IDE
- MySQL statements: The SQ script used to set up the database schema
_ Documentation : Detailed Word Report, PowerPoint Presentation Slides, Project Poster
